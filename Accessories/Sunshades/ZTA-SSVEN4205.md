# ZeroTech 50mm Objective Sunshade for Vengeance 4-20x50 (ZTA-SSVEN4205)

## Summary
A 4-inch (50mm) objective sunshade that threads directly into the objective of Vengeance 50mm riflescopes to reduce glare and improve the sight picture.

## Specifications

| Specification | Value |
| --- | --- |
| Part Number | ZTA-SSVEN4205 |

| Objective Size | 50mm |
| Length | 4 inch |
| Fitment | Threads directly into compatible 50mm objectives |
| Color | Black |

## Key features

- **Reduces glare** — limits excess light entering the objective, especially with the sun low on the horizon.
- **Clearer sight picture** — improves visibility and contrast in bright conditions.
- **Direct thread fit** — screws straight into the Vengeance 50mm objective; no adapter required.
