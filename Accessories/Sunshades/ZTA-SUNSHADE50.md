# ZeroTech 50mm Objective Sunshade (ZTA-SUNSHADE50)

## Summary
A 3-inch (50mm) objective sunshade that threads directly into compatible 50mm ZeroTech riflescopes to reduce glare and improve the sight picture in bright, low-sun conditions.

## Specifications

| Specification | Value |
| --- | --- |
| Part Number | ZTA-SUNSHADE50 |
| Type | Objective sunshade |
| Objective Size | 50mm |
| Length | 3 inch |
| Fitment | Threads directly into compatible 50mm objectives |
| Color | Black |

## Key features

- **Reduces glare** — limits excess light entering the objective, especially with the sun low on the horizon.
- **Clearer sight picture** — improves contrast and viewing comfort in bright conditions.
- **Direct thread fit** — screws straight into compatible 50mm objectives; no adapter required.
