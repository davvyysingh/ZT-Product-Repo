# ZeroTech Universal Binocular Tripod Adapter (ZTA-BA01)

## Summary
A lightweight universal clamp adapter that mounts almost any binocular (30–70mm tube) to a tripod, with an integrated ARCA Swiss dovetail and a 1/4-20 thread for quick-release plates.
