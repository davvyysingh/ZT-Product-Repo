# ZeroTech Neoprene Scope Cover (Large) (ZTA-COVERLG)

## Summary
A protective neoprene scope cover in the large size, suited to Trace and larger-bodied riflescopes — the large option in the ZeroTech Neoprene Scope Covers range (the small size is ZTA-COVERSML).

## Specifications

| Specification | Value |
| --- | --- |
| Part Number | ZTA-COVERLG |
| Type | Neoprene scope cover |
| Size | Large |
| Also available | Small (ZTA-COVERSML) |
| Color | Black |

## Key features

- **Neoprene protection** — guards the riflescope against knocks, dust and moisture in transport and storage.
- **Sized for larger scopes** — fits Trace models and larger-bodied Thrive HD and Vengeance riflescopes; the small size covers the more compact models.

## What's in the box

- ZeroTech Neoprene Scope Cover (Large)

## Fits

Ideal fit:

- Thrive HD 2.5-15x50 — PHR 2 (TH2155P), PHR 2 Illuminated (TH2155P-IR)
- Thrive HD 3-18x56 — PHR 2 Illuminated (TH3186P-IR)
- Thrive HD 6-24x50 — PHR 2 (TH6245P), PHR 2 Illuminated (TH6245P-IR)
- Trace 3-18x50 — R3 (TR3185R3)
- Trace 4.5-27x50 — R3 (TR4275R3), FFP RMG (TR4275F)
- Vengeance 4-20x50 — PHR 2 (VG4205P), PHR 2 Illuminated (VG4205P-IR), R3 (VG4205R3), R3 Illuminated (VG4205R3-IR)

Not suitable — use the small cover (ZTA-COVERSML) instead:

- Thrive 3-9x40 — ZEROPLEX (TH3940), PHR 3 (TH3940-P3)
- Thrive 3-12x44 — ZEROPLEX (TH31244), PHR 3 (TH31244-P3), Mildot (TH31244MD)
- Thrive 4-16x50 — ZEROPLEX (TH41650), Mildot (TH41650MD), PHR 2 (TH41650P)
- Vengeance 3-12x40 — ZEROPLEX (VG3124)
- Vengeance 4.5-18x40 — PHR (VG45184P)

This list is complete for this accessory. The ZTA-COVERLG is a scope cover sold separately, and it fits only the riflescope models listed above as an ideal fit — if a model is not listed here, this cover does not fit it.
