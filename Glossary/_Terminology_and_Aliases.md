# ZeroTech Terminology & Alternate Names (Glossary)

Maps the terms used as values in ZeroTech spec sheets and other technical/product terms to their full meaning and the **alternate names / aliases** customers may use. Use it to recognise when a different word refers to the same thing (e.g. "shake awake" or "MOTAC" = Auto Sleep / Auto ON; "RMS-c" = Shield RMSc; "tan" = FDE). Caveats note where an alias is only approximately equivalent — bench-check before publishing a fit claim.

## Footprint

| Term (as in our specs) | Full name / meaning | Also known as | Notes / caveats |
| --- | --- | --- | --- |
| Shield RMSc | Reflex Mini Sight – compact (Shield Sights) | RMSc, RMS-c, "Shield footprint", Holosun-K class | Slimline/micro pistol standard. Shared by SIG RomeoZero, JPoint, Swampfox Sentinel, Holosun 407K/507K & EPS Carry. CAVEAT: Holosun "K" is a MODIFIED RMSc (recoil-post difference) — usually interchangeable, bench-check. NOT the full-size Shield RMS/SMS; NOT full-size Holosun EPS. |
| Trijicon RMR | Ruggedized Miniature Reflex | RMR footprint, "Trijicon footprint", Holosun-C class | Full-size pistol/rifle standard. Shared by Trijicon SRO/RCR, Holosun 407C/507C/508T. CAVEAT: NOT the Docter/Vortex footprint; RMRcc is a separate, narrower pattern. |
| Aimpoint Micro | Aimpoint Micro mounting standard | T-1 / T-2 / H-1 / H-2 footprint, "Aimpoint Micro / T2" | Tube red-dot RAIL standard (rifle/rail) — not a pistol footprint. Widely cloned by other micro dots. |
| Mini ACOG | Trijicon (Compact) Mini ACOG mount | "Compact ACOG mount / footprint" | Mount-interface category for compact prisms, not a formal footprint like RMR/RMSc. ACOG = Advanced Combat Optical Gunsight. |
| DeltaPoint Pro (DPP) | Leupold DeltaPoint Pro | DPP, DPO (slide-cut label), "DPP / Romeo1 Pro" | SIG Romeo1 Pro shares it. Adapter territory for ZeroTech (not a ZT footprint). Don't confuse Romeo1 (older) with Romeo1 Pro (=DPP). |
| ACRO | Aimpoint ACRO = Advanced Compact Reflex Optic | ACRO footprint | Enclosed pistol footprint. Steiner MPS ~shares it (slightly wider lug — not universally plate-interchangeable). Some sources wrongly say "Combat". |
| Docter / Noblex | Docter/Noblex footprint | "Vortex Venom/Viper / Burris FastFire / Docter" | Docter = Noblex (rebranded 2018). Shared by Vortex Venom/Viper, Burris FastFire, Meopta, EOTech MRDS. CAVEAT: NOT the RMR footprint. |
| Holosun-K vs -C | 407K/507K (K) vs 407C/507C/508T (C) | "K" / "C" footprints | K = RMSc-class (small/slim slides); C = RMR-class (full-size). |
| Shield RMS vs RMSc | RMS = full-size; RMSc = compact | — | Different sizes. A ZeroTech RMSc optic will NOT correctly index a full-size Shield RMS cut. |

| Term (as in our specs) | Full name / meaning | Also known as | Notes / caveats |
| --- | --- | --- | --- |

| Slide cut | Milled optic pocket on a pistol slide | "optics cut", "direct cut", optics-ready | Direct-cut = optic bolts on with no plate. |
| Plate / adapter plate | Piece that adapts a slide/mount to a footprint | mounting plate, optic plate, adapter | Factory plate = from the pistol maker; adapter plate = third-party. |
