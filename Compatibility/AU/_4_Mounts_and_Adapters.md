# Aftermarket Mounts & Adapter Plates

Part of the ZeroTech Red Dot & Prism Firearm Compatibility guide (5 files: 1 Overview · 2 Optics & Footprints · 3 Pistol Fitment · 4 Mounts & Adapters · 5 Coverage Summary).

ZeroTech optics use industry-standard footprints, so they drop into a large third-party ecosystem. Named brands are category examples, not endorsements — confirm the specific part fits your firearm and optic before purchase. On any adapter-plate pistol, state compatibility only with the plate named; never imply a bare slide takes the optic.

## Rail-optic footprints — mount ecosystems

| Footprint | ZeroTech optics | Example aftermarket mount categories |
| --- | --- | --- |
| Aimpoint Micro / T-2 | THRD22, TRRD125, THRD25, THDMP120/-FDE | Very widely supported. Fixed & QD mounts/risers from American Defense, Scalarworks, Reptilia, Unity (FAST), Warne, GG&G, Midwest Industries and others in many exact co-witness heights. |
| Trijicon RMR | THDRS28 (RS28) for rifle/offset use | RMR-pattern rail mounts, 45° offset & piggyback mounts are ubiquitous (the RS28 ships with a Picatinny mount as standard). |
| Mini ACOG | THDP1424 (Variable Prism) | Trijicon ACOG-pattern QD bases, e.g. American Defense AD-B2-C (named in the ZeroTech manual). |

## Pistol adapter plates — when a ZeroTech pistol optic does not drop straight on

| Host slide cut | Adapter needed | Example plate makers / notes |
| --- | --- | --- |
| Slide with a factory MOS-type optic-plate system | MOS → RMSc  (for DM21 / H.A.L.O) | Drop-in MOS→RMSc plates (no milling) from Athena Precision, C&H, TSA, Vector Optics, Optics-Spot. The RMR pattern is reachable via the factory MOS plate. |
| Trijicon RMR-cut slide | RMR → RMSc  (for DM21 / H.A.L.O) | The RS28 fits RMR-cut slides direct. To run an RMSc optic instead, use an RMR→RMSc plate from C&H, EGW, Forward Controls, etc. |
| Slide using a multi-pattern optic-plate system | plate for the required pattern (RMSc or RMR) | Aftermarket plates available for both RMSc and RMR patterns (C&H and others). Adapter plates add height — check zeroing travel; the H.A.L.O 1° shim may help. |
| RMSc-cut slide needing RMR | RMSc → RMR | An RMSc→RMR adapter lets the full-size RS28 run on a slim RMSc slide — usually only worthwhile on larger RMSc pistols. |
| OEM plate system missing the pattern you need | matching-pattern plate | Some factory optic-plate systems don't offer every pattern — source the correct-pattern plate for that slide's system (OEM if offered, else aftermarket). Confirm before claiming fit. |
